# 마일스톤 테스트 사이트

## 2026-10-13 최신 기능 반영

PC 7단계·기본 82개/선택 업무 템플릿, 다중 선행 날짜 계산, QA 연장 영향 확인, 보호 일정·저장 충돌 처리, 역할별 조회와 CSV 열 연결 해제 수정을 반영했습니다. 샘플 프로젝트도 최신 PC 템플릿으로 교체했습니다. 모바일·콘솔 신규 생성은 후속 작업입니다.

로컬 최신 원본의 198개 회귀 테스트와 별도 Firestore 에뮬레이터 권한 테스트 10개가 통과했습니다. 이는 실제 서버 동시 편집·부하·오프라인 검증 완료를 의미하지 않습니다. 이번 배포는 Hosting만 변경합니다. 운영 DB·권한 규칙·인덱스·실제 원본 일정은 변경하지 않습니다.

125%/150% 사용자 화면에서 확인된 간트 날짜 밀집과 대시보드 높이 개선은 아직 반영하지 않았습니다. CSV 이관의 최초 원본 반영 방식도 후속 정리 대상입니다.

## 수정 테이블 검증 모듈

`lib/actual-task-table.js`는 수정 가능한 업무 열과 유효성 검사를 제공하는 공통 함수입니다. ID·원문·담당자·지원 비율·의존성을 보존하며 단계/직군 참조 및 날짜를 검사합니다. `tests/actual-task-table.test.js`는 가상 데이터만 사용합니다.

이 모듈은 아직 공개 관리 화면의 셀 편집 기능에 연결하지 않았습니다. 실제 일정 데이터와 로컬 적용 파일은 이 공개 저장소 및 Hosting에 포함하지 않습니다. 공개 사이트는 최신 PC 템플릿 기반 가상 4프로젝트·328업무를 사용합니다.

Firebase Hosting: https://fmv-schedule.web.app

프로젝트 4개·업무 328개의 가상 샘플 데이터로 화면과 기능을 테스트합니다. 모두 최신 PC 7단계·기본 82개 업무 템플릿으로 생성되며, 세 프로젝트는 진행/한 프로젝트는 완료 상태입니다. 담당자와 자동 선행 날짜 연결도 최신 엔진으로 생성합니다. 관리자·직군 담당자·기획팀장 역할은 상단에서 선택합니다. 각 브라우저에 독립 저장되며 샘플 데이터 초기화로 원복할 수 있습니다. 브라우저 저장 키를 새 버전으로 분리하여 예전 샘플은 삭제하지 않고 새 샘플을 표시합니다.

운영 Firebase DB, 실제 계정 로그인, Google Chat 및 여러 사용자 간 동기화는 연결되지 않습니다. 실제 업무나 개인정보를 입력하지 마세요. 링크를 아는 누구나 접속할 수 있는 공개 테스트 사이트입니다.

## 배포

`npm run verify` 후 Firebase CLI에 로그인하고 `npm run deploy`를 실행합니다. Hosting만 교체하며 DB와 보안 규칙은 배포하지 않습니다.

GitHub Actions는 push/PR 시 검사만 실행합니다. 수동 Run workflow 시 기존 `FIREBASE_SERVICE_ACCOUNT` 시크릿을 사용해 Hosting만 배포합니다. 해당 시크릿의 Hosting 권한은 별도 확인이 필요합니다. 저장소에 키 파일을 추가하지 마세요.

이전 앱은 Git 이력에 보존됩니다. 공휴일 DB 자동 수정 workflow는 제거했습니다. 수정할 화면 코드와 가상 데이터는 public/ 안에 있습니다.
