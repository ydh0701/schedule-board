# 공휴일 자동 동기화

GitHub Actions가 매주 월요일 오전 3시(KST)에 Nager Holidays API를 조회하여 Firestore의 `holidays` 컬렉션을 갱신합니다.

## 필요한 GitHub Secrets

- `FIREBASE_SERVICE_ACCOUNT`: Firebase 서비스 계정 JSON 전체 내용

## 수동 실행

GitHub 저장소의 `Actions` 탭에서 **한국 공휴일 동기화**를 열고 `Run workflow`를 누르면 즉시 실행됩니다.

동기화 대상은 실행 시점의 올해와 내년입니다. 휴일 문서는 날짜를 ID로 사용하므로 같은 날짜는 갱신되고 중복 생성되지 않습니다.
